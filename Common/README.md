# Common native item icons

5 native-rendered 256 × 256 PNGs. Image URLs are pinned to commit `81e50deaf2b5623f78ad6bc5af74b9e927ead379`.

`catalog.json` identifies every icon by item ID, GUID, source Workshop and SHA-256. Unavailable native previews are listed without image URLs. Internal assets are included for coverage; this does not enable them as gameplay loot. Existing Escalation files are preserved.
