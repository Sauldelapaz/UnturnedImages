# Escalation item icons

1144 native item icons exported at 256 × 256 pixels with transparent backgrounds.

- `Items/<item ID>.png`: native icon.
- `catalog.json`: IDs, GUIDs, names, URLs and SHA-256 hashes.
- `links.csv`: item ID, name and URL.

13 items did not yield a usable native icon; these are listed in `catalog.json` and have no image URL. This image catalog includes native compatibility and internal assets; it is not a shop or loot eligibility list.
