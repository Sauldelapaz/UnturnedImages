# Escalation item icons

1295 native-rendered item icons at 256 × 256 pixels: 1144 original Escalation icons and 151 server extension icons.

- `Items/<item ID>.png`: native item icon.
- `catalog.json`: item IDs, GUIDs, names, URLs and SHA-256 hashes.
- `links.csv`: item ID, name and image URL.

13 items did not provide a usable icon and are listed in `catalog.json`. This catalog includes compatibility and internal assets; inclusion does not mean that an item is enabled for shop, crafting, kits or loot.
